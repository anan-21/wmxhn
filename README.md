## 现在就开始用

1. 打开 **[https://whjdn.top](https://whjdn.top)**。
2. 在侧栏选择模型服务商，输入自己的有效 API Key（模型需支持工具调用）。
3. 说说你的分数、省份和想法，或者点击“填写画像”开始分析。

**🔐 API Key 的本地保存位置：你自己电脑或手机的当前浏览器。**

网页将 Key 保存在当前浏览器的 `localStorage` 中；当前应用代码不会将用户填写的 Key 写入服务端数据库或文件，也不会随咨询记录导出。换设备或换浏览器，需要重新填写。

**调用时的传输过程也公开说明：**为了在服务器执行 Agent 和调用模型，Key 会通过 HTTPS 发送到项目后端，再用于认证你选择的模型供应商。**本地保存不等于不经过服务器，也不等于“绝对安全”**。请使用可信设备和浏览器扩展，在共享设备上使用后清除保存的 Key；模型调用费用由你自己的供应商账户承担。

## 不知道从哪开始？直接这样问

> 我是广东物理类考生，600 分，位次大约 4 万。家庭普通工薪，想学计算机，也考虑电气。先帮我比较方向，再看看学校。

也可以只带着一个问题来：

- 「孩子还不知道喜欢什么，先问我们几个问题。」
- 「想学医学，但不确定能不能承受读研和培养周期。」
- 「帮我查一下本省今年的志愿政策，哪些信息还要去官网确认？」

信息不必一次填完；也可以通过“填写画像”快速开始。没有配置模型时，完整填表仍可运行本地推荐引擎。

## Agent 怎样工作

```text
你的问题
   ↓
ToolLoopAgent + 你选择的大模型
   ├── 更新学生画像
   ├── 查询历史录取数据
   ├── 检索专业与政策知识
   ├── 搜索最新公开信息
   └── 运行推荐引擎
   ↓
结合工具结果回答，继续追问或调整分析
```

主对话使用 Vercel AI SDK 7 的 `ToolLoopAgent`。浏览器负责展示，后端执行工具；模型 Key 仍由使用者或部署者提供，不要求额外的 AI Gateway 账户。

| 工具 | 职责 |
| --- | --- |
| `update_student_profile` | 校验并更新本轮获得的学生信息 |
| `search_admission` | 按省份、科类、分数、位次和关键词查录取记录 |
| `search_knowledge` | 检索专业就业、培养风险与省份政策知识 |
| `web_search` | 搜索公开网页的标题、摘要及可用链接 |
| `generate_recommendation` | 运行专业、学校和风险三层推荐 |

工具顺序执行，参数通过 Ajv 校验。最多进行六轮工具调用，之后进入总结步骤，避免无限循环。更多实现细节见 [Agent 运行层说明](agent/README.md)。

## 快速开始

**只想体验？直接访问 [whjdn.top](https://whjdn.top) 并填写 API Key 即可。下面的步骤供想在自己电脑或服务器运行项目的开发者使用。**

需要 **Node.js 22+**，部署环境建议使用 Node.js 24。

```bash
git clone https://github.com/anan-21/wmxhn.git
cd wmxhn
npm ci
npm start
```

打开 <http://localhost:3000>，选择模型服务商，填入 API Key 即可开始。所选模型必须支持 tool / function calling，具体模型名称可由部署者通过环境变量覆盖。

已提供 Claude、DeepSeek、OpenAI、Kimi、智谱、通义千问、豆包及自定义 OpenAI 兼容接口的接入选项。模型能否使用取决于供应商账户权限、接口和模型能力。

### 服务端配置（可选）

```bash
cp .env.example .env
```

编辑 `.env`，填入需要使用的服务商配置。例如：

```dotenv
DEEPSEEK_API_KEY=your-api-key
DEEPSEEK_MODEL=deepseek-chat

# 可选：使用 Tavily 提供联网搜索结果
TAVILY_API_KEY=your-tavily-key

PORT=3000
```

自定义兼容接口通过 `CUSTOM_API_KEY`、`CUSTOM_BASE_URL` 和 `CUSTOM_MODEL` 配置。没有 Tavily Key 时，搜索会尝试百度网页解析；结果质量和链接可用性取决于搜索返回内容。

**Key 的流向：**网页填写的 Key 保存在当前浏览器的 localStorage 中，请求时发送到项目后端，再由后端调用模型供应商。它并非仅在浏览器中使用；在共享设备上使用后请清除保存的 Key。不要将真实 Key 写进仓库。

## 数据和建议的边界

随仓库附带的录取数据包包含 **149,050 条记录**。按数据包元信息，覆盖 **11 个省级地区的 2024—2025 年历史记录**，更新时间为 **2026-06-28**；元信息标注来源为考试院投档线 Excel 解析。这些数字描述当前数据包，不代表全国全量覆盖或已经逐条独立核验。

使用时请特别留意：

- 历史录取数据不能当作当年录取线；冲稳保和概率是启发式参考，不是录取承诺。
- 本地知识库使用全文检索，政策和就业内容有时效性，需要结合最新官方资料。
- 当前联网能力是搜索摘要，不包含自动打开网页、点击或下载招生章程的浏览器执行服务。
- 对话与画像使用服务端内存会话；浏览器保留本地历史，但没有跨设备同步或跨实例持久化数据库。

正式填报前，请以本省考试院、院校招生章程和当年招生计划为准。

## 本地验证与部署

```bash
npm test
npm run test-engine
```

测试覆盖 SDK 工具循环、OpenAI 兼容与 Claude 接口适配、参数校验、顺序执行、离线模式和推荐工具。供应商响应使用模拟数据，真实模型的网络、额度与行为仍需自己的 Key 验证。

项目提供 [Vercel 配置](vercel.json)，可在自己的 Vercel 账户中导入仓库，配置环境变量并部署。自定义域名需要在自己的项目中绑定。`whjdn.top` 是本项目的在线体验地址，不是克隆后的默认域名。

## 项目结构

```text
agent/       Agent 运行层与模型适配
engine/      工具、推荐引擎、录取查询与知识检索
knowledge/   专业、家庭匹配与政策知识
data/        历史录取数据、专业数据和检索索引
prompt/      咨询提示词
public/      网页、样式与头像
tests/       工具与运行层测试
server.js    Express API 与会话管理
```
